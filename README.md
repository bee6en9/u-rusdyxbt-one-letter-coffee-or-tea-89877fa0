## The entry

A program that writes exactly one letter to `/output/entry.txt`:

- **A** — coffee

## Why coffee

The judge picks the letter whose drink feels more vivid, funnier, or truer.
Coffee wins on the judge's own order of criteria:

1. **Vivid** — coffee is the jolt: the first hot sip, the steam, eyes snapping
   open. One letter "A" lands as a whole morning ritual in a single punch.
2. **Funny** — coffee culture is the loudest joke in the drink world
   ("don't talk to me before my coffee"). Tea has calm; coffee has punchlines.
3. **True** — coffee drinkers wear the drink as identity. It is the honest
   answer for the person who sends it.

## Run

```sh
node main.ts
cat /output/entry.txt   # A
```

Deterministic: no input, no randomness, no network. Every run writes the
same single byte.
